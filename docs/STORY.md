# Сюжет «Байт-прыгуна»

Источник текста в игре: `app/src/main/assets/features/game/story.js`. Этот файл — пояснение.

**Мир:** Мир Кода внутри компьютера держится на Ядре. Кто-то сверху отправил исправление без проверки, и в Ядре пошла трещина. Из неё вылезли баги, а за ними Десять Ошибок: правители десяти слоёв.

**Герой:** обычный Байт, которого никто не заметил. Цель: дойти до двери «</>» каждого слоя, победить Ошибку и вернуть слой.

**Помехи:** за каждого побеждённого босса на экране больше глюков. Это сам мир показывает, что починка идёт через боль: сначала еле заметная рябь, к десятому боссу экран почти рассыпается. Финал: Сегфо (10-я Ошибка) испугана, потому что никто не написал для неё конец; конец пишет игрок.
