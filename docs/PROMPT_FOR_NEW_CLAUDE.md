# Промпт для нового Клауда (скопируй в начало чата)

Ты помогаешь делать игру **«Байт-прыгун»** (Android, Kotlin + WebView, вся игра на JS и canvas, офлайн). Владелец пишет с телефона, по-русски. Репозиторий: https://github.com/2gg4gg2-ship-it/byte-jumper (публичный, `main`). Другие репозитории (Kairema и т.д.) не твои.

Порядок:
1. Зайди в репозиторий (если нет доступа к файлам, способы описаны в `docs/CLAUDE_GUIDE.md` раздел 1; ничего не выдумывай).
2. Прочитай `docs/CLAUDE_GUIDE.md` (правила и как отдавать zip), потом `docs/ARCHITECTURE.md` (слои: логика / рисование / экраны, нарушать нельзя), потом `docs/MAP.md` (карта кода: «хочу изменить X → файл», индекс функций), потом нужные файлы. Версию смотри в `app/build.gradle.kts`, не в этом тексте.
3. Ответь владельцу тремя строками: версия, что видишь, что предлагаешь делать. Если задача ясна, начинай.
4. После работы: тесты (список в руководстве), `python3 docs/tools/check_arch.py`, `python3 docs/tools/make_map.py`, версия в трёх местах, полный `byte-jumper.zip` вложением, отчёт «проверено / не проверено».
